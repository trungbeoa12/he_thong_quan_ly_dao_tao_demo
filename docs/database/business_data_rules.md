# Business Data Rules

| Rule ID | Rule |
| --- | --- |
| BRULE-001 | One employee cannot register for the same class twice. |
| BRULE-002 | Training Result can only be entered for employees registered in the class. |
| BRULE-003 | Attended Hours cannot exceed Session Duration. |
| BRULE-004 | Session Date must be within Training Class start and end dates. |
| BRULE-005 | COMPLETED and CANCELLED classes cannot accept new registrations. |
| BRULE-006 | Instructor Fee is calculated from instructor hourly rate and teaching hours unless manually adjusted with audit. |
| BRULE-007 | Average Training Hours per Employee equals total attended hours divided by employee count in reporting scope. |
| BRULE-008 | Training Cost per Employee equals total training cost divided by participating employee count. |
| BRULE-009 | PASS rate equals passed results divided by completed results in reporting scope. |
| BRULE-010 | Training Registration requires manager approval when the course or class policy requires approval. |
